EASIEST GITHUB UPLOAD
1. Unzip this ZIP on your computer.
2. Open your GitHub repository.
3. Choose Add file -> Upload files.
4. Select ALL files inside this folder (including all .jpg files).
5. Drag them together into GitHub.
6. Click Commit changes.

IMPORTANT: Do NOT upload only index.html. The .jpg files must also appear in the
main repository list next to index.html.

QUICK TEST BEFORE GITHUB
Double-click index.html on your computer. The page should open in your browser
and the photos should be visible. If they are visible locally, the package is intact.
